# Groww — REF-G01 / REF-G02

Sources:
- https://groww.in/updates/portfolios-on-groww
- https://groww.in/updates/portfolio-analysis-on-groww

![Groww portfolio example — externally hosted by Groww](https://cms-resources.groww.in/uploads/258_1x_shots_so_11zon_9c3653f135.jpg)

Observe: prominent total, a small set of key submetrics, scanning lists, chart hierarchy. Especially relevant: Groww's portfolio collections support names, emojis, colors and belonging to more than one collection.

Apply to Expense Tracker: total spend, category totals, time trend; multi-tag spend should not be double counted in the grand total.

Avoid: trading-specific information density and financial jargon.

Original image remains at the source; it is not copied into this repository.
