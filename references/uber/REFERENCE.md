# Uber — Dominant next-step CTA (REF-U01)

**Approved inspiration:** one unmistakable prominent forward action on each focused screen.

**Use for:** Continue, Review and Save Expense buttons across the guided entry journey.

**Desired behavior:** consistent placement, large touch target, high contrast, action-oriented label; secondary actions do not compete with the primary action.

**Avoid:** map layouts, transport terminology, multiple competing CTAs.
